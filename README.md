# Multi-Agent Travel Day Planner

**This is the isolated UI rebuild.** Open [UI-REBUILD.md](UI-REBUILD.md) for the new dashboard's setup and limitations. It runs on frontend port 5174 and backend port 8002, separately from the original version.

A college proof of concept that makes four AI agents' collaboration visible: a planner coordinates transport, dining, and activities specialists to produce a day itinerary.

The application lives in [`travel-planner/`](travel-planner/README.md). The original brief is preserved in [`architecture-plan.md`](architecture-plan.md) and [`implementation-instructions.md`](implementation-instructions.md).

See the application README for setup, architecture, limitations, and verification commands.
